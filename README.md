# CppME Chapter 10

This repository contains the sample projects and exercises for Chapter 10 of the C++ Programming Made Easy series.

## Overview

The project includes a Visual Studio solution (`CppME_Chapter10.slnx`) and multiple example subprojects covering chapter topics such as:

- example 10.7
- example 10.8
- example 10.9
- example 10.10
- example 10.11
- example 10.12
- example 10.20
- example 10.21
- example 10.23
- example 10.24

The main starter file is `CppME_Chapter10.cpp`, and the repository is organized as a set of chapter-based C++ sample programs.

## Repository structure

- `CppME_Chapter10.cpp` - main project source file
- `CppME_Chapter10.vcxproj` - Visual Studio C++ project file
- `CppME_Chapter10.slnx` - Visual Studio solution file
- `CppME_Chapter10_Example10.*` - individual chapter example directories

## Build and run

This project is configured for Microsoft Visual Studio on Windows.

1. Open `CppME_Chapter10.slnx` in Visual Studio.
2. Select the desired configuration and platform.
3. Build the solution.
4. Run the application from the IDE or the generated executable.

## Notes

This repository is intended for educational use and demonstrates C++ concepts from Chapter 10 of the book.
